# Pdl.ai Web Showcase

Official static landing page for the **Pdl.ai** Discord bot, built for GitHub Pages.

## Overview

- **Fluid Discord Interface** : Dark obsidian theme with native Discord chat previews, reply spines, and interactive audio controls.
- **Interactive Slash Commands** : Live command selector where Pdl.ai explains each music, moderation, and utility command.
- **Live Server Integration** : Real-time synchronization with the official Pdl.ai Support server via the Discord Widget JSON API and embedded widget.

## Structure

- `index.html` : Main layout and Discord UI components
- `css/styles.css` : Custom animations, floating header, and solid color tokens
- `js/script.js` : Interactive command studio, fluid navigation, and live Discord API sync
- `images/` : Bot animations and community member avatars
